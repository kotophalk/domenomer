# ⚡ Bulk DR Checker

Массовая проверка **Ahrefs Domain Rating (DR)** для списка доменов. Локальное веб-приложение: вставили список — получили таблицу с DR, отфильтровали, выгрузили в CSV.

Работает через бесплатный эндпоинт Ahrefs `domain-rating-free` — он не тратит лимиты подписки, но требует ключ APIv3.

## Возможности

- Ввод списка доменов текстом или загрузкой TXT/CSV; URL и `www.` нормализуются, дубли убираются
- Таблица результатов с цветовыми бейджами DR (0–20 / 21–50 / 51+), сортировкой по любому столбцу и фильтром по диапазону DR
- Экспорт в CSV ровно того, что видно в таблице (с учётом фильтра и сортировки), с UTF-8 BOM для Excel
- Соблюдение лимита Ahrefs API (60 запросов/мин): очередь с ограничением конкурентности и паузами между запросами
- Автоматический повтор при `429 Too Many Requests` — общая пауза по `Retry-After` или экспоненциальный backoff, до 3 повторов на домен
- Кнопка «Стоп» (или Esc): уже полученные результаты сохраняются и доступны для экспорта
- Ноль зависимостей: Python 3 (стандартная библиотека) и ванильные HTML/CSS/JS

## Требования

- Python 3.7+
- Ключ Ahrefs APIv3 — создаётся в Ahrefs: **Account settings → API keys** (доступно владельцам и админам воркспейса, срок жизни ключа — 1 год; [подробнее](https://docs.ahrefs.com/docs/api/reference/api-keys-creation-and-management)). Сам эндпоинт бесплатный и не расходует API units, см. [документацию](https://docs.ahrefs.com/en/api/reference/public/get-domain-rating-free)

## Быстрый старт

```bash
git clone git@github.com:kotophalk/domenomer.git
cd domenomer
cp .env.example .env      # вписать AHREFS_API_KEY=...
./start.sh                # или: python3 server.py
```

Открыть <http://localhost:3000>, вставить домены, нажать «Проверить DR» (или Ctrl+Enter).

Ключ можно задать и переменной окружения — она имеет приоритет над `.env`:

```bash
AHREFS_API_KEY=... python3 server.py
```

## Как это устроено

```
браузер ──GET /api/dr?target=example.com──▶ server.py ──Authorization: Bearer <ключ>──▶ api.ahrefs.com
        ◀────────── {"domain_rating": …} ───────────  ◀────────────────────────────────────
```

- **`server.py`** — HTTP-сервер на `http.server`: раздаёт статику и проксирует `/api/dr` в Ahrefs, подставляя ключ. Ключ никогда не попадает в браузер. Ошибки Ahrefs нормализуются в `{"error": "..."}`, заголовок `Retry-After` пробрасывается.
- **`app.js`** — вся логика фронтенда. Запросы идут через пул воркеров (по умолчанию 4) с интервалом 1 с между стартами. При 429 очередь целиком встаёт на паузу и домен повторяется. Настройки — константы в начале файла:

  ```js
  const RATE_LIMIT_PER_MIN = 60;  // лимит Ahrefs API
  const MAX_CONCURRENCY = 4;      // одновременных запросов
  const MAX_RETRIES = 3;          // повторов при 429
  ```

- **`index.html`**, **`style.css`** — разметка и тёмная тема.

## Ограничения

- 60 запросов в минуту — значит, 500 доменов займут около 8–9 минут. Это лимит Ahrefs, а не приложения.
- Приложение рассчитано на локальный запуск: сервер слушает `0.0.0.0:3000` без авторизации, не публикуйте его наружу.
